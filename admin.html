🔐 Admin Login

पहिल्यांदा Admin तयार करायचा असल्यास

Supabase Dashboard → Authentication → Users → Add user करून Admin email/password तयार करा. त्यानंतर खालील SQL एकदाच चालवा:

UPDATE public.profiles SET role='admin', active=true WHERE id='AUTH-USER-UUID';

AUTH-USER-UUID म्हणजे Authentication → Users मधील त्या Admin चा User UID. हा टप्पा एकदाच करायचा आहे.
